# Project context for future agents

- Purpose: German web app for reviewing meal-specific insulin factors from FreeStyle Libre 3 Plus CGM data and manually injected Fiasp. Development discussion and code can be in English; all user-facing UI text is German.
- Nightscout is the exclusive source of truth for CGM readings, carbs, injections and the time-specific correction-factor (`sens`) schedule. SQLite mirrors source data, caches the current Nightscout profile for local analyses and stores versioned calculation-model settings. Apply the current profile schedule to all analyses; do not reconstruct historical profile schedules. Calculated meal factors are recomputed, not written to Nightscout. Credentials and app login live only in the untracked .env.
- Insulinfaktor means **IE per KE**, with 1 KE = 10 g carbohydrate (the user's Libre diary also uses 1 BE = 10 g). Korrekturfaktor is separate, time-specific **mg/dL per IE**. Nightscout I:C is g/IE = 10 / (IE/KE).
- One factor is calculated for each breakfast, lunch or dinner window. Sum **all** recorded carbohydrate events and **all full rapid-insulin IE** from meal start up to, but not including, the endpoint. Split boluses and later corrections count in full even minutes before the endpoint; prior injections and basal insulin do not count. Do not revive the former triangular Fiasp action weighting; legacy peak/duration settings are ignored.
- Default endpoint: meal start + 180 minutes. If the next main meal is >120 and <180 minutes later, use the last valid CGM value within 15 minutes before it. If a second main meal cannot be separated this way, show a blocker. CGM values at exact endpoints are linearly interpolated with a maximum 15-minute surrounding gap.
- Model equation: IE/KE = 10 × (ΔG + Σ[rapid IE × time-specific KF]) / Σ[carbs in g × time-specific KF]. Use Decimal arithmetic and show the inputs, endpoint, doses, assumptions and equation. Full effect of late insulin, full carb effect by the endpoint, and no background glucose drift are **model assumptions**, not physiological facts or dosing advice.
- The current PoC runs locally via docker compose up -d --build at 127.0.0.1:8765; keep Docker/VPS deployment viable. Python standard library serves the API and static site. Run python3 -m unittest discover -s tests -v and node --check web/app.js after calculation or UI changes.
